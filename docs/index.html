How it is built

  1. Power Query cleans the workbook into FactSales and seven dimension tables.
  2. DimDate is a DAX calendar; Order Date is the active relationship.
  3. Measures convert currency row by row and return blank, rather than a wrong total, when a rate is missing.
  4. 2019 is a partial year, so a matched-cutoff year-over-year measure is used.
  5. A navy and teal theme and exact pixel layouts keep all six pages consistent.
